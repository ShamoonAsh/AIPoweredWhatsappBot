# AI-Powered WhatsApp Bot (Meta Cloud API + Google Gemini)

A WhatsApp chatbot that answers with replies generated by Google Gemini and remembers the conversation. Each user gets their own chat history, which is cleared after a period of inactivity.

**Tech stack:** Python, Flask, Meta WhatsApp Cloud API, Google Gemini API (`google-genai`), Ngrok

## How it works

```
WhatsApp user ──► Meta Cloud API ──► Ngrok tunnel ──► Flask /webhook
                                                         │
                                                         ▼
                                       Gemini (with per-user chat history)
                                                         │
WhatsApp user ◄── Meta Cloud API ◄── POST /messages ◄────┘
```

- `GET /webhook`: answers Meta's verification handshake (`hub.challenge`).
- `POST /webhook`: receives incoming messages, returns `200` right away, and replies from a background thread so Meta doesn't resend the message.
- Ignores duplicate deliveries, checks `X-Hub-Signature-256` when an app secret is set, and splits replies longer than 4096 characters into several messages.
- Commands: `/reset` starts a new conversation, `/help` shows usage.

## Project structure

```
app.py            Flask app: webhook endpoints and message routing
bot/config.py     Settings loaded from .env
bot/whatsapp.py   WhatsApp Cloud API client (send, mark read, check signatures)
bot/gemini.py     Gemini chat with per-user memory
```

## Setup

### 1. Install

```bash
python -m venv venv
venv\Scripts\activate          # Windows  (macOS/Linux: source venv/bin/activate)
pip install -r requirements.txt
copy .env.example .env         # macOS/Linux: cp .env.example .env
```

### 2. Get credentials

- **Gemini:** create an API key at https://aistudio.google.com/apikey and put it in `GEMINI_API_KEY`.
- **WhatsApp:** at https://developers.facebook.com create an app of type *Business*, then add the **WhatsApp** product. Under *WhatsApp > API Setup*:
  - copy the **access token** into `WHATSAPP_TOKEN` (the temporary token expires after 24h; use a System User token for anything long-lived)
  - copy the **Phone number ID** into `WHATSAPP_PHONE_NUMBER_ID`
  - add your own phone number as a test recipient
- Set `WHATSAPP_VERIFY_TOKEN` to any random string you choose.
- Optional: copy *App settings > Basic > App secret* into `WHATSAPP_APP_SECRET` to turn on signature checks.

### 3. Run locally and expose with Ngrok

```bash
python app.py                  # starts on http://localhost:5000
ngrok http 5000                # in a second terminal
```

### 4. Register the webhook

In *WhatsApp > Configuration > Webhook*:
- **Callback URL:** `https://<your-ngrok-id>.ngrok-free.app/webhook`
- **Verify token:** the same value as `WHATSAPP_VERIFY_TOKEN`
- Click **Verify and save**, then subscribe to the **messages** field.

Send a WhatsApp message to the test number and the bot will reply.

## Notes

- Conversation history is kept in memory, so it is lost when the server restarts. For production, move it to Redis or a database.
- The free Ngrok URL changes every time Ngrok restarts. When it does, update the callback URL in Meta.
